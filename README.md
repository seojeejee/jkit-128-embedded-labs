# JKIT-128-1 임베디드 시스템 실험

호서대학교 임베디드 실험 수업에서 수행한 주차별 AVR 제어 실습과 기말 프로젝트를 정리한 저장소입니다.

기말 프로젝트는 두 플레이어가 증가하는 숫자를 각자 버튼으로 멈추고, 더 큰 값을 선택한 플레이어가 점수를 얻는 게임입니다. 먼저 4점을 얻으면 LED와 멜로디로 승리를 알립니다.

## 학습 내용

- LED 점등 패턴과 비트 연산
- 스위치 입력과 버튼 디바운싱
- 4자리 7-세그먼트 멀티플렉싱
- 외부 인터럽트와 타이머
- 부저 주파수, 버튼음, 배경음과 승패 멜로디

## 기말 프로젝트 구현

- INT4·INT5 외부 인터럽트로 플레이어별 숫자 정지
- 0부터 99까지 증가하는 두 숫자를 4자리 7-세그먼트에 표시
- 정지값 비교와 라운드 점수 계산
- LED 8개를 이용한 양쪽 플레이어 점수판
- Timer3 기반 부저 주파수 생성
- Timer0 기반 배경음과 승패 효과음
- 4점 도달 시 최종 멜로디와 LED 점멸

## 저장소 구성

```text
notebooks/
├─ weekly_labs.ipynb    # LED, 스위치, 부저, 7-세그먼트, 인터럽트 실습
└─ final_project.ipynb  # 기말 프로젝트 개발 코드
src/
└─ main.c               # 기말 프로젝트 최종 AVR C 코드
```

## 실행 환경

코드는 JKIT-128-1 실습 키트의 포트 구성에 맞춰 작성했으며 AVR 헤더와 레지스터를 사용합니다. AVR-GCC 또는 Atmel Studio 계열 환경에서 대상 MCU와 포트 매핑을 확인한 뒤 빌드해야 합니다.

보관된 자료에는 장치 동작 영상이나 계측 결과가 없어 코드 구조와 수업 실습 기록을 중심으로 정리했습니다.
